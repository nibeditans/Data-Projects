# Project-Based Case Studies

This folder contains **project-based case studies** derived from completed data projects and lab work.

These case studies do not aim to document the full project pipeline. Instead, they extract and focus on **specific decision narratives** that emerged from real projects, such as a key analytical choice, a trade-off, or a business question that required structured reasoning.

A single project may result in **multiple case studies**, each addressing a different problem or perspective within the same project context.


## What Defines a Project-Based Case Study?

In this folder, a project-based case study typically emphasizes:

- The real-world or analytical context of a project  
- A clearly scoped problem or decision within that project  
- Reasoning behind analytical choices and assumptions  
- Insights derived from analysis and how they informed decisions  
- Impact, limitations, and potential next steps  

The focus is on **why certain choices were made**, not on reproducing every step of implementation.


## Relationship to Projects and Lab Work

- **Projects / Lab folders** contain execution artifacts such as code, notebooks, dashboards, and reports.
- **Project-based case studies** interpret selected parts of that work by making the reasoning and decision-making explicit.

Think of projects as the raw material and case studies as the structured argument built from that material.


## Organization Notes

- Each case study is written as a standalone Markdown file.
- Multiple case studies may reference the same underlying project.
- Numbering is used only for organization and reading order, it does not imply importance or ranking.

Not all projects in this repository have associated case studies, only selected work that benefits from deeper analytical explanation is documented here.
