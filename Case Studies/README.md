# Case Studies

This folder contains a curated collection of **data-related case studies** that focus on **reasoning, decision-making, and analytical thinking**, rather than just tools or implementation.

A case study here is not a project dump, notebook, or dashboard. Instead, it is a **structured narrative** that explains how a problem was framed, how decisions were reasoned through, and how insights led to conclusions or recommendations.

## What a Case Study Represents Here?

In this space, a case study emphasizes:

- Problem context and framing  
- Assumptions, constraints, and trade-offs  
- Analytical reasoning (Math, logic, or data-backed)  
- Key insights and decisions  
- Impact, limitations, and possible next steps  

Tools, code, and visuals may be referenced when they add clarity, but they are **supporting evidence**, not the centerpiece.

Each case study is written as a standalone Markdown file and can be read independently.


## Types of Case Studies

This folder is organized into two broad categories:

### 1. Problem-Based (Independent) Case Studies

These case studies are **standalone reasoning exercises**, not tied to a full project or production pipeline.

Each problem-based case study starts with a clearly defined problem and focuses on reasoning through it to reach a conclusion. These are especially useful for demonstrating analytical thinking under constraints, or concept-driven analysis.

### 2. Project-Based Case Studies

These case studies are derived from **existing data projects or lab work**. A single project may give rise to multiple case studies, each focusing on a specific decision, question, or analytical angle rather than the entire pipeline.

Project-based case studies highlight how analysis performed within a real project was translated into **insights and decisions**.


## How to Navigate This Folder

- Each case study is self-contained and can be read on its own.
- The order of files does not imply importance or ranking.
- Not every project or experiment in this repository has an associated case study, only selected work is documented here.

This folder will grow incrementally over time, with an emphasis on **quality and clarity over quantity**.
