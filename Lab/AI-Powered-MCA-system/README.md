# AI-Powered Marketing Campaign Intelligence System

This project simulates a marketing campaign and demonstrates how data can be transformed into actionable business insights using AI. Instead of focusing on complex modeling, the goal is to showcase the last mile of analytics, converting performance metrics into clear, decision-oriented insights.

## Tech Stack

- Python (NumPy, Pandas)
- Requests (API integration)
- OpenRouter (LLM access)
