# Nutrition Time Series Analysis (2022–2025)

This is my end-to-end Time Series Analysis project, built using a synthetic nutrition dataset. I have generated this dataset using NumPy, stored it into a Pandas DataFrame, and then saved it inot a CSV file for reuse across different notebooks.

I created this project to deeply understand how time-based data works in real-world scenarios, not just from an analysis point of view, but also from a data storytelling and business perspective.

## Tools & Technologies I Used

### Programming & Analysis
- **Python**
- **NumPy**
- **Pandas**
- **Matplotlib**
- **StatsModels**
- **Scikit-learn**

### Visual Storytelling
- **Power BI**
